# Codebase reviews

This directory contains dated, read-only codebase reviews and the prompts used to produce them.

Reviews are resumable artifacts. A review's `README.md` is its table of contents and records coverage, assumptions, exclusions, findings, and remaining work. Findings have stable IDs so later implementation work can refer to them without repeating the analysis.

The first Astra review is defined by [the CSK Hub review prompt](./astra-codebase-review-prompt.md).
